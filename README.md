# 🧠 BrightMind — Test Your Brain

**Learn something new — free, forever. No paywall. No card. No signup.**

BrightMind is a free micro-learning app. A better, open alternative to paid learning apps like SmartyMe.

Live demo: https://jaysonsmarayag.github.io/Testyourbrain/Testyourbrain.html

## ✨ What it does

- **12 full lessons** you can finish in 2-3 minutes each
- **4 tracks:**
  - 🧠 Brain & Psychology
  - 💰 Money & Business
  - ⚡ Productivity & Habits
  - 💬 Communication
- **Quiz after every lesson** with instant feedback + explanations
- **XP, levels & streaks** — Novice → Curious → Sharp → Brilliant
- **Progress tracking** saved in your browser
- **100% free** — no account, no trial, no subscription

## 📚 Lessons included

## 🚀 How to use

Just open `Testyourbrain.html` in any browser. No build step, no server needed.

Or host it free on GitHub Pages:
1. Upload all files to this repo
2. Go to **Settings > Pages**
3. Branch: **main** → Save
4. Open: `https://jaysonsmarayag.github.io/Testyourbrain/Testyourbrain.html`

## 🛠️ Tech

- Single HTML file
- HTML + CSS + JavaScript
- No dependencies, no framework
- Works on mobile + desktop
